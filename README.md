## 🚀 Featured Infrastructure Projects

### ⚙️ RTT-Engine (Advanced 3D Engine Architecture)
*A high-performance, lightweight 3D engine built to explore real-time hardware interfaces and animation systems.*
* **Dual-Backend RHI:** Built an abstraction driving pixel-identical rendering pipelines across OpenGL 4.5 and Vulkan 1.0, validated via offscreen headless readbacks.
* **Advanced Visual Pipeline:** Implemented compute-based AMD FSR3 upscaling, temporal motion vector generation, logarithmic clustered Forward+ illumination, and PBR Cook-Torrance BRDF.
* **Locomotion Mechanics:** Features custom hardware-skinned animations mixed with advanced KD-Tree-driven Motion Matching trajectory predictions.
* **Deterministic Guardrails:** Features a custom internal test gate running **731 integration tests across 99 suites** before allowing the runtime executable to boot.

### 🎮 Sprite-Player 2D Architecture
*An internal exploratory engine prototype showcasing custom component handling and 2D physics loop execution.*
* **Tech:** C++, SFML API, Custom Data-Driven Pipelines
* **Core:** Decoupled Entity-Component-System (ECS) environment managing state engines (Idle, Walk, Jump).
* **Physics:** Deterministic gravity configurations with pixel-perfect fixed-timestep collision boundaries.

### 🧩 8-Puzzle Solver (Real-Time Visualizer)
*An object-oriented simulation displaying optimal mathematical states across a 3x3 array layout.*
* **Tech:** C++17, SFML Interface, STL Algorithms
* **Core Logic:** Implemented A\* search traversal with structural path node weighting calculations ($f(n) = g(n) + h(n)$).
* **Performance:** Leverages an optimized Manhattan Distance heuristic model with frame-delayed state updates.

### 🌀 pathFinder (Algorithmic Comparison Environment)
*A multi-threaded interactive simulation designed to evaluate map-traversal and maze-solving efficiencies.*
* **Tech:** C++17, SFML Graphics Modules
* **Features:** Built side-by-side benchmarking races comparing Breadth-First Search (BFS), Depth-First Search (DFS), and Heuristic A\* configurations in real time.
